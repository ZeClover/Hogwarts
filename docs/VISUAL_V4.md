# Referência e assets Visual V4

Fonte: `Hogwarts_1890_Visual_V4.zip` e prompt F0/F1 enviados pelo usuário. O protótipo foi lido como referência visual; seu JavaScript de simulação/localStorage não foi transportado para o modelo de segurança.

O CSS original foi preservado como base em `public/style.css`. A interface mantém serifas clássicas, madeira/tons escuros, bordas envelhecidas, brilho moderado, fotografias grandes e navegação direta. Login, perfis e formulários administrativos foram construídos no mesmo sistema visual.

**Mapa provisório:** a restauração convencional fornecida tem áreas retocadas visíveis. Sua qualidade e as posições ilustrativas dos marcadores aguardam revisão do Mestre. Não houve restauração ou geração adicional por IA. Os marcadores são links HTML cujas coordenadas/visibilidade vêm do servidor; não são permissões embutidas na imagem.

As duas imagens de exemplo do Profeta foram retiradas de `public/assets/` para não disponibilizar conteúdo de demonstração como publicação. As demais 28 imagens WebP foram validadas por decodificação no build. Nenhuma nova imagem foi gerada por IA.

As capturas em `docs/screenshots/` são de bancos temporários de teste, com os cinco personagens confirmados. Contas `@test.invalid`, grupos e alterações de permissão pertencem às fixtures; não são contas ou acontecimentos oficiais de campanha. O banco real não acompanha o código-fonte.

Os arquivos visuais continuam sujeitos aos direitos de seus titulares; este repositório não atribui uma nova licença aos assets fornecidos.
